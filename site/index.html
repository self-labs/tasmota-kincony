Tasmota for KinCony

Flash the Tasmota builds made for KinCony boards straight from the browser. The official Tasmota binaries do not fit these boards: the AG8 needs the full IR driver with Ethernet, and the A16 v3 needs the PCF8574 driver that every official build leaves out.

Before you start

  • Chrome or Edge on a desktop computer. Flashing uses Web Serial, which Firefox, Safari, Android and iOS do not have.
  • A USB-C cable that carries data, not only power.
  • If the board is not found, put it in download mode: hold DW, tap RST, release DW, and try again.

Back up the factory firmware first

Installing erases the whole flash, including the KinCony KCS firmware and everything learned in it. The browser cannot read the flash back, so take the backup with esptool before anything else: 

python -m esptool --chip esp32s3 --port COM3 --baud 460800 read_flash 0x0 0x1000000 backup-16MB.bin

The file must be exactly 16,777,216 bytes. Writing it back with write_flash 0x0 backup-16MB.bin restores the board as it came.

KinCony AG8

ESP32-S3, 8 IR emitters, IR receiver, W5500 Ethernet, RS485, RS232
This browser cannot flash. Use Chrome or Edge on a desktop. Web Serial needs HTTPS or localhost.

Tasmota with the full IR driver, so every one of the 8 emitters can be chosen per command, air conditioner protocols included, plus Ethernet, the serial, Modbus and TCP bridges, MAX31865 and 1-Wire. Tested on the board, Ethernet included with no USB cable plugged in.

After flashing

  1. Set up Wi-Fi when the installer offers it, or join the tasmota-XXXX access point and open http://192.168.4.1.
  2. In the Console, send the template, then Module 0 as a separate command: 
Template {"NAME":"KinCony AG8","GPIO":[0,5536,5600,0,0,0,0,0,0,1056,1057,1058,1059,1060,1061,0,0,0,0,0,0,1062,0,0,0,0,0,0,0,0,5568,736,704,672,0,0,1063,1088],"FLAG":0,"BASE":1}
  1. Then EthType 8 for the W5500 and SetOption58 1, so remotes of unknown protocols can be learned.
  2. For Home Assistant, add the Tasmota IR integration from HACS.

Full guide, in Portuguese: KinCony AG8 no Home Assistant.

KinCony KC868-A16 v3

ESP32-S3, 16 relays, 16 inputs, 4 analog inputs, W5500 Ethernet, RS485, RF 433 MHz, RTC, display
This browser cannot flash. Use Chrome or Edge on a desktop. Web Serial needs HTTPS or localhost.

Tasmota with the PCF8574 driver for the 32 channels, the DS3231 clock, the SSD1306 display, the TCP bridge and RF 433 MHz. Not flashed on a board yet: the binary has been checked for every driver, but nothing has been tested on hardware.

After flashing

  1. Set up Wi-Fi when the installer offers it, or join the tasmota-XXXX access point and open http://192.168.4.1.
  2. In the Console, send the template, then Module 0 as a separate command: 
Template {"NAME":"KinCony A16v3","GPIO":[0,5536,5600,0,4704,4707,4705,4706,1152,640,608,0,0,0,0,5568,9408,9440,1120,0,0,0,0,0,0,0,0,1314,0,0,0,736,704,672,0,0,1312,1313],"FLAG":0,"BASE":1}
  1. Then EthType 8 for the W5500.
  2. Upload pcf8574.dat and display.ini under Consoles → Manage File System, and restart.
  3. SetOption114 1, or closing input 1 switches relay 1.

Full guide, in Portuguese: KinCony KC868-A16 v3 no Home Assistant.
