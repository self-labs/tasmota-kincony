Tasmota for KinCony

Web flash the Tasmota builds made for KinCony boards: plug the board in by USB-C, click install, and the browser does the rest. No Python, no esptool, no PlatformIO.

Before you start

  • Chrome or Edge on a desktop computer. Web flashing uses Web Serial, which Firefox, Safari, Android and iOS do not have.
  • A USB-C cable that carries data, not only power.
  • Board not found? Put it in download mode: hold DW, tap RST, release DW, and retry.

Back up the factory firmware first

Installing writes the factory image: bootloader, partition table, application and safeboot, at offset 0, with the whole flash erased first. That is what makes a board coming from the KinCony KCS firmware boot clean, and it is also what removes KCS and everything learned in it. A browser cannot read the flash back, so take the backup with esptool before anything else: 

python -m esptool --chip esp32s3 --port COM3 --baud 460800 read_flash 0x0 0x1000000 backup-16MB.bin

The file must be exactly 16,777,216 bytes. Writing it back with write_flash 0x0 backup-16MB.bin restores the board as it came.

KinCony AG8

Infrared controller, ESP32-S3
This browser cannot flash. Use Chrome or Edge on a desktop. Web Serial needs HTTPS or localhost.
8 IR emitters IR receiver air conditioner protocols W5500 Ethernet RS485 and RS232 Modbus and TCP bridge MAX31865 1-Wire

The full IR driver, so a command can pick which of the 8 emitters it leaves through, next to everything the standard ESP32-S3 build has. Running here since September 2026, Ethernet included with no USB cable plugged in.

After flashing

  1. Set up Wi-Fi when the installer offers it, or join the tasmota-XXXX access point and open http://192.168.4.1.
  2. In the Console, paste the template, then send Module 0 as a separate command: 
Template {"NAME":"KinCony AG8","GPIO":[0,5536,5600,0,0,0,0,0,0,1056,1057,1058,1059,1060,1061,0,0,0,0,0,0,1062,0,0,0,0,0,0,0,0,5568,736,704,672,0,0,1063,1088],"FLAG":0,"BASE":1}
  1. EthType 8 for the W5500, and SetOption58 1 so remotes of unknown protocols can be learned.
  2. For Home Assistant, add Tasmota IR from HACS: every key you learn becomes a button, and every air conditioner a climate entity.

KinCony KC868-A16 v3

16 relays, ESP32-S3
This browser cannot flash. Use Chrome or Edge on a desktop. Web Serial needs HTTPS or localhost.
16 relays 16 inputs 4 analog inputs W5500 Ethernet RF 433 MHz DS3231 clock SSD1306 display RS485

The PCF8574 driver for the 32 channels, which no official build has, plus the clock, the display and the TCP bridge. Not flashed on a board yet: the binary has been checked driver by driver, and nothing more.

After flashing

  1. Set up Wi-Fi when the installer offers it, or join the tasmota-XXXX access point and open http://192.168.4.1.
  2. In the Console, paste the template, then send Module 0 as a separate command: 
Template {"NAME":"KinCony A16v3","GPIO":[0,5536,5600,0,4704,4707,4705,4706,1152,640,608,0,0,0,0,5568,9408,9440,1120,0,0,0,0,0,0,0,0,1314,0,0,0,736,704,672,0,0,1312,1313],"FLAG":0,"BASE":1}
  1. EthType 8 for the W5500.
  2. Upload pcf8574.dat and display.ini under Consoles → Manage File System, and restart.
  3. SetOption114 1, or closing input 1 switches relay 1.

Where the firmware comes from

Both builds come from cateim/Tasmota, branch tasmota-kincony, which is Tasmota plus the two environments these boards need. Every push there builds both boards and publishes a release, and this page serves the binaries of the latest one.

Updating to a newer Tasmota is merging the upstream release into that branch and pushing: the build runs, a release comes out, and the site picks it up within a day, or straight away from its Actions tab. The install button always writes the whole factory image, so a board flashed from here is always on the release shown below.
